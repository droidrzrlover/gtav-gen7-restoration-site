Installation preparation

These are precautionary steps, not a complete installer procedure. Do not overwrite game files until a verified package and version-specific instructions are available.

  1. Confirm that your existing GTA V installation launches normally before changing anything.
  2. Back up the installation or create a separate working copy, and preserve original executable and archive files.
  3. Keep a record of the installed game version and your current mod setup.
  4. Wait for the official package, checksums and exact installation instructions before applying any files.
  5. After installation instructions are published, verify file integrity and test the restoration separately from your original installation where possible.

Backup & rollback

Keep original game files available so changes can be reversed. A verified rollback procedure will identify which files the release changes, where backups are stored, and how to restore the original installation.

Do not assume that removing a launcher or mod folder restores every changed file.
